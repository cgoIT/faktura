# Sicherheit

faktura verarbeitet Personendaten und Rechnungen. Wenn du eine Sicherheitslücke findest:

- **Bitte nicht öffentlich melden** (kein Issue, kein Pull Request). Nutze auf GitHub „Security → Report a vulnerability“
  (privater Sicherheitshinweis) dieses Repositories.
- Beschreibe, was passiert, wie man es reproduziert und welche Version betroffen ist. **Hänge keine echten Kundendaten, Zugangsdaten oder ungeschwärzte Logs an**;
  erfundene Beispieldaten genügen.
- Das Projekt wird in der Freizeit gepflegt: Eine Rückmeldung erfolgt nach bestem Bemühen, ohne feste Frist und ohne Zusage eines Zeitplans.

Unterstützt wird jeweils der aktuelle Stand des Hauptzweigs. Hinweise zum sicheren Betrieb (Anmeldung, Reverse Proxy, Backups) stehen in
[docs/betrieb.md](docs/betrieb.md). Die Software wird ohne Gewähr bereitgestellt (siehe [LICENSE](LICENSE)).
